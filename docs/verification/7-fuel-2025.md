# Issue #7: 2025 ordinary gasoline taxes

The existing fuel formula now has 2025 inputs for the federal excise and all 13 reference jurisdictions.
There are no engine, schema, driving-default, carbon, childcare or other-year data changes.
All rates below are published amounts, not estimates. Dollars per litre are cents divided by 100.

## Published rates

Federal gasoline excise is 10 cents per litre throughout 2025. The NRCan source explicitly distinguishes its
2026 temporary suspension from the pre-existing rate. Ordinary fuel taxes exclude carbon, GST/HST/QST and
the clean-fuel compliance amounts sometimes included in regulated pump-price schedules.

## Calendar-year treatment and carbon separation

No ordinary gasoline rate in this table changes within calendar 2025, so each is a full-year scalar.
Alberta's March 1 table boundary changes locomotive fuel, not its 13-cent gasoline rate. Manitoba's
12.5-cent rate begins January 1, 2025. Ontario's 9-cent rate continues through 2025. Newfoundland and Labrador's
7-cent reduction leaves 7.5 cents throughout 2025; the March 2025 announcement extends it to March 31, 2026.
The ARTM budget published in December 2025 states its 3-cent amount has not been indexed since 1992.
The April 1 consumer carbon-price removal is already represented separately in the existing carbon data.

The new independent fixture checks full-year ordinary fuel alongside Alberta's existing gasoline carbon:
`litres × 0.1761 × 90 / 365`. Carbon and credits must match the same household calculated without ordinary fuel.
The browser check retains the exact existing carbon/rebate checks and adds 1,000-litre ordinary fuel totals
of $230 in Alberta and $322 in Québec. Its Alberta fuel summary is $273 after the rounded $43 carbon component.

## Existing golden-result audit

The baseline was `3788dfc:tests/golden/2025.json`. All 148 households across 13 jurisdictions were checked:
1,924 results, of which 1,300 change and 624 remain identical. The only changed stored output fields are
`gross`, `total`, `avg` and `grossAvg`. Every household input, scenario identifier, other result field, assertion
and tolerance remains unchanged. No other annual or existing feature fixture's expected values change.

The [per-case impact audit](7-fuel-2025-impact.json) records each changed household/jurisdiction, litres,
independently transcribed published rate, ordinary fuel amount, and every before/after expected value.
The audit procedure was:

1. Clone current 2025 data and remove only ordinary `fuelTax`; keep carbon and all other rules.
2. Calculate each original household and require its entire stored snapshot to equal the original fixture.
3. Independently calculate litres as `max(0, km) × max(0, efficiency) / 100`, then multiply by the separately
   transcribed federal plus provincial plus regional full-year rates above. No engine fuel helper or YAML
   fuel rate is used for this expected delta.
4. Add that amount to the original unrounded gross and net totals, derive their ratios using original cash,
   and round only the four stored fields to four decimal places using the existing fixture convention.
5. Require the entire new engine snapshot to equal this independently adjusted old snapshot exactly.
   Write those independent expected fields into the fixture; no golden-capture command was used.
6. Compare the resulting fixture directly with the original git object to verify every input and unrelated
   output field remains equal. There are no additional rounding-only changes.

The maximum addition is $1,618.75 for scenario 32 in BC: 4,375 litres × $0.37. Gross changes from
$40,659.606 to $42,278.356 and total from $38,135.094 to $39,753.844. Scenario 0 in BC adds $539.46:
1,458 litres × $0.37, changing gross and total from $20,350.9241 to $20,890.3841.

## Explicitly frozen test specimens: reviewer attention

Before this issue, several tests used 2025 because ordinary fuel data was absent. Activating real data would
silently change the meaning of their deliberately isolated specimens. The orchestrator approved making the
missing component explicit while preserving all original households, expectations, assertions and tolerances:

- The two engine no-fuel tests explicitly delete fuel as well as their already-removed carbon data.
- The single `fuel-no-data` coverage case adds `omitFuelData: true`; only that flagged case strips fuel.
- The original other-income golden runner preserves its frozen 2025 context without fuel (and already without
  carbon). Its 2026 cases retain fuel. The original fixture is unchanged.
- The history-carbon specimen already replaces brackets, prices and rebates with synthetic values to isolate
  carbon; it now explicitly removes ordinary fuel as well. Its original fixture is unchanged.

This is restricted to named missing-data/synthetic or historical specimens, not all 2025 tests. The new
`fuel-2025.json` fixture has 18 independently calculated cases using real 2025 data: all 13 jurisdictions,
zero distance, zero consumption, absent driving input, fractional litres, and disabled credits. These cases
fail if real fuel data is removed. A separate full-calendar test checks every federal/provincial/regional
schedule, and the published-reference test checks all 13 rates at 1,000 litres.

unchanged values, 19 opted-out unchanged values, 32 additions, 29 removals and 6 replacements.
Comparing that report with the same report using `3788dfc`'s 2025 data establishes that all 379 changed entries,
all 112 unchanged entries and all 53 previous structural entries are identical. Those flags are inherited
from the existing year data, not introduced by this change. The only new structural entries are 14 added
`fuelTax` objects: federal and all 13 jurisdictions, individually supported in the table above.
The full year-diff output accompanies the pull request.
